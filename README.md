## Overview

HuBERT is a self-supervised speech representation model trained by predicting **discrete hidden units** (cluster assignments) for masked audio frames — analogous to masked language modeling in BERT. This project analyzes what these representations capture at the **phonetic level**, using forced alignments from LibriSpeech as ground truth.

## Background: How HuBERT Works

HuBERT follows a **two-stage** self-supervised training process:

1. **Offline clustering** — k-means is applied on MFCC features (or previous HuBERT representations) to generate discrete pseudo-labels
2. **Masked prediction** — the model observes partially masked audio frames and learns to predict the cluster assignment of each masked frame

```
Audio waveform
    ↓
CNN feature extractor  (convolution over raw waveform)
    ↓
Transformer encoder    (12 layers, 768 dims)
    ↓
Discrete unit prediction  (k-means targets during training)
```

At inference time, the **transformer hidden states** are used as speech representations. These representations have been shown to encode:
- **Phonetic information** (different phones cluster in representation space)
- **Speaker identity** (different speakers have distinct global offsets)
- **Prosody** (rhythm, stress, intonation)

## Expected Methodology

### 1. Load Audio and Alignments
```python
import torchaudio
from transformers import HubertModel, Wav2Vec2Processor

waveform, sr = torchaudio.load("1272-128104-0000.flac")
# HuBERT expects 16 kHz mono
```

### 2. Extract HuBERT Representations
```python
model = HubertModel.from_pretrained("facebook/hubert-base-ls960")
processor = Wav2Vec2Processor.from_pretrained("facebook/hubert-base-ls960")

inputs = processor(waveform.squeeze(), sampling_rate=16000, return_tensors="pt")
with torch.no_grad():
    outputs = model(**inputs, output_hidden_states=True)

# outputs.hidden_states: tuple of (B, T, 768) for each of 12 layers
# T = number of frames (1 frame ≈ 20ms)
```
